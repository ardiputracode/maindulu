# BIOS server

Tidak ada BIOS berhak cipta yang dibundel. Pengguna dapat memilih BIOS lokal tanpa mengunggahnya.

Untuk BIOS yang boleh Anda distribusikan, simpan di folder ini dan tambahkan entri ke `/catalog/bios.json`:

```json
[{ "id": "bios-psx", "name": "BIOS PlayStation", "consoleId": "psx", "url": "/bios/nama-file.bin" }]
```

Semua file pada folder public dapat diunduh pengunjung. Ini bukan penyimpanan privat.
